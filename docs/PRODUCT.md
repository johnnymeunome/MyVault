# Product

## Promise

Vaulta aims to make ownership of local credential data feel clear, calm and modern. The product should communicate privacy and technical honesty without looking like an administration dashboard.

## M0 outcomes

The shell demonstrates the primary navigation model: choose a vault, browse and filter entries, inspect details, create or edit a login, generate a password, and lock the experience. All changes are session-only.

## Experience principles

1. **Local is visible.** Status language says what is local, mocked or unavailable.
2. **Dense, not cramped.** Information is compact enough for desktop use while controls retain accessible targets.
3. **Danger is explicit.** Destructive actions are labeled and visually distinct.
4. **Security claims are earned.** The prototype warning remains present on the lock screen and in documentation.
5. **Keyboard-first.** Search and common actions are reachable from a command palette.

## Non-goals for M0

Cryptography, KDBX parsing, secret persistence, sync, browser integration, biometrics, autofill, telemetry and online accounts.
