# Roadmap

## M0 — Product shell

Navigable interface, mock data, architectural boundaries, design system, tests and documentation. **Current milestone.**

## M1 — Experimental KDBX core

Open a copy of a test KDBX file in read-only mode. Validate format compatibility and error handling before exposing broader files.

## M2 — Safe writes

Create, edit and save a copy of a vault with atomic writes, backups, recovery and interoperability tests.

## M3 — Local protections

Auto-lock, reviewed clipboard handling, memory protection, keychain integration and a redacted logging policy.

## M4 — Experimental release

Signed builds, cross-platform verification, import and recovery workflows, and published threat documentation.

No milestone will be called production-ready before an independent audit.
